No vendes "consultoría" genérica. Vendes resultados concretos. Ejemplos de servicios con alta demanda:

- **Diagnóstico estratégico** — dónde está la empresa y qué frena su crecimiento
- **Optimización de operaciones** — reducir costos, mejorar procesos

## El workflow completo con IA

### Fase 1 — Captación del cliente

```
Tú defines el nicho (ej: restaurantes, clínicas, retail)
    ↓
IA redacta contenido LinkedIn + emails de prospección
    ↓
Calendly automatiza la reunión de discovery
    ↓
Claude prepara preguntas clave para esa reunión
```

### Fase 2 — Diagnóstico (aquí la IA te ahorra 80% del tiempo)

```
Cliente rellena formulario de onboarding (Tally o Typeform)
    ↓
Subes respuestas a Claude → genera análisis DAFO preliminar
    ↓
Tú haces 1 entrevista de 60 min con el cliente
    ↓
Claude transforma tus notas en informe de diagnóstico completo
    ↓
Tú revisas, ajustas y presentas → percibes como experto
```

### Fase 3 — Entrega del proyecto

```
Claude genera borradores de planes estratégicos, modelos financieros narrativos
    ↓
Tú aportas criterio, experiencia y personalización
    ↓
Notion o Google Slides para presentaciones
    ↓
Loom para grabar explicaciones asíncronas al cliente
```

### Fase 4 — Administración (casi 100% automatizada)

```
Holded o Wave → facturas automáticas
DocuSign → contratos con plantillas IA
Notion → seguimiento de proyectos
Google Calendar + Calendly → gestión de agenda
```
